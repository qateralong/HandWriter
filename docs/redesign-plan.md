# HandWriter 2.0: план изменений

Дата обсуждения: 2026-10-05. Статус: план утверждён, работа не начата.

## 1. Переход на Rust + Tauri

- Ядро (шрифты, раскладка текста, импорт SVG/DXF/PDF/PNG, разбиение на проходы, gcode) переписывается с Python на Rust.
- Окно — Tauri: собственное окно приложения (WebView2 на Windows, WebKitGTK на Linux) без Chrome/Edge. Один исполняемый файл вместо `HandWriter.exe` + `_internal`.
- Интерфейс пишется заново на HTML/CSS/JS внутри Tauri (см. п. 2).
- Платформы: Windows и Linux.
- Язык интерфейса переключается в настройках (сейчас язык зашивается при сборке, два отдельных exe).

Как переносим, чтобы ничего не сломать:
1. Прогнать текущую Python-версию на наборе примеров (тексты, SVG, DXF, PDF, картинки, A4/A3) и сохранить gcode как эталон.
2. Rust-версия должна давать тот же результат (с допуском на округление).
3. Перенести 219 существующих тестов.

Слабые места Rust по библиотекам: DXF (ezdxf) и PDF (pymupdf) — часть импорта придётся дописывать или брать pdfium.

## 2. Новый интерфейс

Масштабная переработка. Сначала — режим «Чертёж», затем «Тетрадный».

### Главный экран

```
┌──────────────────────────────────────────────────────────────────┐
│ [лого] HandWriter         [ Один лист | Все листы ]     [🖨] [⚙] │
│ [Чертёж | Тетрадный]           ‹  проход 2 из 4  ›               │
│                                                                  │
│                                                                  │
│                центральная область: лист / листы                 │
│                                                                  │
│                                                                  │
│ [Загрузить файл] [⚙ чертёж ▴]  Время печати: 1 ч 12 мин  [Скачать gcode] │
└──────────────────────────────────────────────────────────────────┘
```

- **Слева вверху:** логотип и надпись HandWriter, под ними переключатель режимов «Чертёж / Тетрадный».
- **Вверху по центру:** переключатель вида «Один лист / Все листы».
  - Листы — это проходы одного чертежа (A4 — 2 прохода, A3 — 4).
  - «Один лист» — показывается один проход и появляются кнопки перелистывания.
  - «Все листы» — все проходы сразу, как сейчас, но в переработанном виде.
- **Справа вверху:** кнопка управления принтером по кабелю (см. п. 3) и кнопка настроек.
- **Центр:** лист или листы.
- **Слева внизу:** загрузка файла и рядом кнопка параметров чертежа.
- **Внизу по центру:** суммарное время печати всех проходов (всегда сумма).
- **Справа внизу:** скачивание gcode — всегда архив всех проходов.

### Параметры чертежа (быстрое меню)

Кнопка рядом с загрузкой файла. По нажатию разворачивается небольшое меню на малую часть экрана (не панель настроек). Внутри — то, что меняется от чертежа к чертежу:
- формат (A4 / A3 / свой размер);
- ориентация;
- масштаб (вписать, 1:1, проценты, подбор под проходы);
- способ рисования картинки (по средним линиям / штриховкой, шаг и направление штрихов).

Рамка, сдвиг, толщина линий, порог и DPI для картинок из этого меню вынесены в окно настроек.

В названиях и подписях рамка не называется «ГОСТ».

### Тетрадный режим

- Вместо загрузки файла вводится текст: на месте кнопки загрузки — кнопка, по которой разворачивается редактор текста.
- Всегда показывается один лист.
- Настройки почерка (шрифт, случайность, линовка, переносы и т. п.) — так же, отдельной кнопкой с быстрым меню, как параметры чертежа.

### Настройки

Открываются кнопкой справа вверху как панель поверх главного экрана (не отдельное окно). Вкладки слева:

| Вкладка | Что внутри |
|---|---|
| Основные | Приложение: тема, язык (может требовать перезапуска) и т. п. |
| Настройки печати | Скорости (рисование, перемещение, Z), высоты карандаша, упрощение пути, рамка, сдвиг, толщина линий, создание тестовых файлов проходов (вкл/выкл) и прочее, связанное с печатью |
| Настройки принтера | Размер стола (всей пластины), доступная область (куда достаёт карандаш), отражение осей, запас до границ и т. п. |
| Дополнительные | Порог и DPI для картинок и всё, что не вошло в остальные вкладки |

Если настроек мало, вкладки можно объединить.

Мастер калибровки достижимости убираем: его заменяет пульт управления по кабелю.

### Темы

- Светлая: бежевый и белый.
- Тёмная: тёмно-синий и серый.

## 3. Принтер по кабелю (USB)

Flying Bear Ghost 5, Marlin, USB-последовательный порт (вероятно, CH340).

- Оба варианта работы: gcode на SD-карту (как сейчас) и печать по кабелю напрямую.
- Открывается отдельной кнопкой на главном экране (справа вверху, рядом с настройками). На кнопке — индикатор связи.
- Панель выезжает справа и не закрывает лист: лист остаётся виден, и во время печати по кабелю на нём отображается текущее положение карандаша и то, что уже нарисовано.
- Содержимое панели:
  - подключение: выбор порта, подключить / отключить, состояние;
  - пульт: перемещение карандаша по X/Y кнопками с выбором шага, карандаш вверх/вниз, домой по X/Y, «запомнить точку как ноль»;
  - печать: проходы по очереди, между проходами — подсказка, как повернуть лист; прогресс, пауза, стоп, аварийная остановка (`M112`).
- Печать по кабелю: построчная отправка с номерами строк и контрольными суммами, повтор при ошибке.
- Во время печати по кабелю нужно запрещать сон компьютера: обрыв связи испортит лист.
- Linux: пользователю нужна группа `uucp` для доступа к `/dev/ttyUSB*`. Windows: драйвер CH340.

## Порядок работ

1. Эталоны gcode из текущей версии.
2. Ядро на Rust + каркас Tauri.
3. Новый интерфейс: режим «Чертёж», затем «Тетрадный».
4. Печать по USB, пульт, отображение положения карандаша.

## Баг текущей версии: линия в конце печати

В конце печати карандаш возвращается в ноль и чертит по листу прямую от последней точки.

Что в файле сейчас (`handwriter/gcode.py`, `handwriter/calibration.py`): перед возвратом карандаш поднимается — `G0 Z4.00`, затем `G0 X0.00 Y0.00`. То есть по gcode линии быть не должно; нужно понять, почему подъём не срабатывает на принтере.

Исправлено в 2.0: в конце печати (и проверочного файла калибровки) карандаш поднимается на `printer.end_lift` (по умолчанию +10 мм к высоте подъёма, то есть Z14) и остаётся на месте, без переезда в ноль.
